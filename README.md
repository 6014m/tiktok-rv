# tiktok-rv
Builds TikTok with the open-source [icysymmetra Morphe patches](https://github.com/icysymmetra/tiktok-patches-for-morphe) (Feed filter: hide ads / lives / images / shop / stories, etc.) using the [j-hc builder](https://github.com/j-hc/revanced-magisk-module) via mentalblank's config. Signed with a key that exists only in this repo.

Download: Releases → latest → the .apk. Uninstall stock TikTok first (same package name, different signature).

## Stock APK
Mirrors block GitHub runners, so the stock TikTok 46.2.3 APK (APK variant, nodpi — not a bundle) is uploaded by hand as an asset on a release tagged `stock`. The workflow pulls it from there. Any filename ending in .apk works.
